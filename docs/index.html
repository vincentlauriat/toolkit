  • /audit-report

    Generate exhaustive audit dossiers on any company, product, technology, or market — like a strategy consulting firm.Générez des dossiers d'audit exhaustifs sur n'importe quelle entreprise, produit, technologie ou marché — comme un cabinet de conseil en stratégie.針對任何公司、產品、技術或市場，產出詳盡的稽核檔案——就像一家策略顧問公司。

    --depth quick|full · --lang en|fr · --mode parallel|sequential|solo · --swot · --esg · --rh · --brief · --watch · --app-mode

What an audit containsCe que contient un audit一份稽核包含什麼

Up to 10 Markdown sections, plus machine-readable artifacts.Jusqu'à 10 sections Markdown, plus des artefacts lisibles par machine.最多 10 個 Markdown 章節，外加機器可讀的產出物。

Each run produces a structured audit-{subject}/ folder. The optional dimensions (ESG, SWOT, HR) are only generated when you ask for them.Chaque exécution produit un dossier structuré audit-{subject}/. Les dimensions optionnelles (ESG, SWOT, RH) ne sont générées que si vous les demandez.每次執行都會產生一個結構化的 audit-{subject}/ 資料夾。選用面向（ESG、SWOT、人資）只有在你要求時才會產生。

  1. HistoryHistorique歷史

  2. MarketMarché市場

  3. TechnicalTechnique技術

  4. PricingTarification定價

  5. CompetitionConcurrence競爭

  6. FinancialsFinances財務

  7. Future outlookPerspectives未來展望

  8. ESG

  9. SWOT

  10. HRRH人資

Alongside the Markdown: _data.json · _sources.json · _manifest.json — so the dossier stays machine-readable.À côté du Markdown : _data.json · _sources.json · _manifest.json — pour que le dossier reste lisible par machine.Markdown 之外還有：_data.json · _sources.json · _manifest.json——讓檔案保持機器可讀。

InstallInstaller安裝

Two commands inside Claude Code.Deux commandes dans Claude Code.在 Claude Code 中執行兩道指令。

# 1. add the marketplace
> /plugin marketplace add vincentlauriat/toolkit

# 2. install the plugin — or browse them all with /plugin
> /plugin install audit-report@vincentlauriat-toolkit
